Now we need to know how controller receives data from the client 
THere are three Important Way's:

	Annotation				Get Data From 				Example
-------------------------------------------------------------------
1. @PathVariable			URL							/employee/101
2. @RequestParam			Query Parameter				/employee?department=IT
3. @RequestBody				Request Body				JSON Data

#3. @RequestBody
- Suppose we are creating Employee and The client has snet data in JSON format 
	that data is too structured to convient to put into the URL
	then client send it in Request Body
	Example: POST /api/employee
	with body :
	{
		"name": "Anuj",
		"department": "IT",
		"salary": 52000
	}
	Spring MVC can convert that JSON into a java object using 
	"@RequestBody"
	flow : JSON -> HTTP Request Body -> DispatcherServlet -> Spring MVC -> @RequestBody -> Java Object
